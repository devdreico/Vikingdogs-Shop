# VikingDogs

Tienda React/Vite inspirada en `EJEMPLO`, migrada al nicho de cuidado para perros usando el catálogo visual de `REAL`.

## Ejecutar

```bash
npm install
npm run dev
```

El catálogo, imágenes y textos viven en `src/main.jsx`. Los precios, número de WhatsApp y endpoint de Formspree están marcados como datos editables porque no fueron incluidos en `REAL`.
